# AthirAI — Intelligent Fragrance Formulation

> **AI-powered perfume formulation assistant**  
> Une plateforme intelligente dédiée aux parfumeurs, laboratoires, fabricants et professionnels de la parfumerie.

---

## 1. Présentation

**AthirAI** est une application SaaS d'aide à la formulation de parfums qui combine :

- une base structurée de matières premières ;
- une bibliothèque de formules ;
- une IA de formulation ;
- un moteur de recherche sémantique ;
- des règles de formulation et de sécurité ;
- l'optimisation des coûts ;
- un assistant interactif capable de modifier progressivement une formule.

L'objectif n'est pas de créer simplement un chatbot qui « invente » des parfums.

AthirAI doit devenir un **véritable assistant de R&D en parfumerie**, capable d'analyser une intention olfactive, rechercher des connaissances existantes, proposer une formule cohérente, expliquer ses choix et aider le parfumeur à l'améliorer.

### Positionnement

**AI-powered perfume formulation assistant**

AthirAI accompagne le professionnel depuis l'idée initiale jusqu'à une formule de travail exploitable en laboratoire.

# 17. Les trois fonctionnalités principales

## 17.1 Trouver une formule

L'utilisateur décrit son besoin.

Exemple :

> « Je cherche un parfum masculin frais, boisé, élégant, avec une bonne tenue et un coût raisonnable. »

AthirAI recherche les formules pertinentes.

Résultat :

```text
Formule A
Similarité : 91 %

Formule B
Similarité : 87 %

Formule C
Similarité : 84 %
```

---

# 18. Créer une formule

L'utilisateur fournit une intention.

Exemple :

> « Crée un parfum féminin floral et élégant avec une ouverture agrume, un cœur floral blanc et un fond musqué. Je veux une bonne tenue et un coût matière inférieur à X DA/kg. »

AthirAI :

1. analyse la demande ;
2. crée le profil olfactif ;
3. sélectionne les matières candidates ;
4. applique les contraintes ;
5. recherche des formules similaires ;
6. génère une composition ;
7. optimise les proportions ;
8. vérifie les contraintes disponibles ;
9. explique les choix.

---

# 19. Modifier une formule

L'utilisateur peut demander :

> « Rend-la plus fraîche. »

ou :

> « Moins sucrée. »

ou :

> « Augmente la tenue. »

ou :

> « Réduis le coût de 20 %. »

AthirAI doit produire une nouvelle version sans détruire la précédente.

---

# 20. Comparaison avant / après

Exemple :

| Matière | Avant | Après | Variation |
|---|---:|---:|---:|
| Matière A | 8 % | 6 % | -2 % |
| Matière B | 4 % | 7 % | +3 % |
| Matière C | 2 % | 3 % | +1 % |

Puis :

### Explication

- diminution de A pour réduire la douceur ;
- augmentation de B pour renforcer la fraîcheur ;
- augmentation de C pour renforcer le fond.

# 21. Architecture IA

AthirAI ne doit pas dépendre uniquement d'un LLM.

## Architecture hybride

```text
Utilisateur
     ↓
Analyse de la demande par IA
     ↓
Profil olfactif structuré
     ↓
Recherche RAG
     ↓
┌───────────────┬────────────────┐
│ Formules      │ Matières       │
│ similaires    │ compatibles    │
└───────────────┴────────────────┘
     ↓
Moteur de formulation
     ↓
Optimisation
     ↓
Validation des contraintes
     ↓
LLM
     ↓
Explication
     ↓
Formule proposée
```

---

# 22. Pourquoi une architecture hybride ?

Un LLM seul peut :

- halluciner une matière ;
- proposer des proportions incohérentes ;
- oublier une contrainte ;
- inventer des informations ;
- produire une formule mathématiquement valide mais techniquement mauvaise.

Le moteur hybride réduit ces risques.

### Le LLM

Comprend l'intention humaine.

### Le moteur de recherche

Trouve les connaissances pertinentes.

### Le moteur de formulation

Travaille sur les proportions.

### Le moteur de contraintes

Vérifie les règles connues.

### L'optimiseur

Recherche la meilleure solution selon les objectifs.

---

# 27. Confidentialité

Les formules d'un laboratoire peuvent être extrêmement sensibles.

AthirAI doit donc prévoir :

- isolation des données par organisation ;
- permissions ;
- chiffrement ;
- journalisation ;
- contrôle des accès ;
- historique ;
- sauvegardes ;
- possibilité de désactiver l'utilisation des données privées pour l'entraînement.

Une formule privée ne doit jamais être rendue visible à une autre organisation.

---

# 28. Réglementation et sécurité

AthirAI ne doit pas présenter une formule comme automatiquement sûre uniquement parce qu'elle est mathématiquement cohérente.

Les données réglementaires doivent être traitées séparément.

Selon le marché cible, le système pourra intégrer des données et règles issues des référentiels applicables, notamment les exigences pertinentes de l'industrie et les standards réglementaires.

### Principe

```text
Suggestion IA
     ↓
Contraintes connues
     ↓
Vérifications
     ↓
Avertissements
     ↓
Validation humaine
```

AthirAI est un **outil d'aide à la formulation**, pas un remplacement du responsable technique ou réglementaire.

# 43. Données : point critique

La qualité d'AthirAI dépend fortement de la qualité des données.

Il faut distinguer :

### Données publiques

Informations légalement accessibles.

### Données sous licence

Données obtenues auprès de fournisseurs ou partenaires.

### Données propriétaires

Données appartenant aux utilisateurs.

### Données générées

Formules créées pendant l'utilisation de la plateforme.

Il ne faut pas construire le produit autour de la récupération illégale de formules confidentielles de grandes marques.
